## Description (Required - Up to 4000 characters)

```
NammaMeter is your trusted digital auto rickshaw meter for accurate fare calculation on every ride.
Whether you're an auto rickshaw driver managing your fleet or a passenger verifying fares, NammaMeter
provides real-time calculations with transparency and precision.

KEY FEATURES:

🚕 FOUR PROFESSIONAL METER STYLES
Choose your preferred meter display:
• Super Mechanical - Classic mechanical meter design for traditional users
• Super Electronic - Advanced electronic meter with night mode indicator
• Golden Eagle - Premium aesthetic with elegant design
• Bright Digital - Modern LCD-style display for clarity

💰 ACCURATE FARE CALCULATION
• Real-time fare calculation based on distance and time
• Fare rules engine with active rule highlighting
• Browse fare rules before your trip in the For Hire state
• Itemised fare breakdown on trip completion
• Support for multiple cities with city-specific rates
• Automatic night fare multipliers
• Waiting time charges with customizable intervals
• Minimum fare protection

📍 INTELLIGENT LOCATION TRACKING
• GPS-based distance measurement
• Real-time map view of your route
• Continuous tracking with background location updates
• Location replay for trip verification

⏱️ TRIP MANAGEMENT
• One-tap trip start and stop
• Pause trips with dedicated waiting mode
• Complete trip history with detailed analytics

🎨 CUSTOMIZABLE EXPERIENCE
• Multiple meter display modes (Full view / Display only)
• Digit wheel style options (Disk / Drum)
• Light and dark mode themes
• Portrait and landscape orientation support
• City-specific fare configuration

⚙️ MULTI-CITY SUPPORT
Configure different cities with:
• Base fare amounts
• Per-kilometer rates
• Per-minute waiting charges
• Night time fare multipliers
• Custom rate schedules

📊 TRIP HISTORY & ANALYTICS
• Complete trip records with timestamps
• Fare, distance, and duration tracking
• Search and filter capabilities

🔐 PRIVACY & RELIABILITY
• All calculations performed locally on your device
• No unnecessary cloud storage
• Background location tracking with permission controls
• Persistent trip data storage

Perfect for:
✓ Auto Rickshaw and auto-rickshaw drivers
✓ Ride-sharing professionals
✓ Passengers verifying fares
✓ Fleet managers tracking operations
✓ Fare verification and dispute resolution

NammaMeter takes the guesswork out of auto rickshaw fares. With precise GPS tracking, configurable
rates for any city, and multiple meter designs, you'll always know exactly what the fare
should be.

Requires: iOS 17.6+
No in-app purchases. No advertisements. No hidden fees.
```

## Reviewer Instructions

### Getting Started:
1. Launch app - Main meter view displays immediately
2. Tap "Start trip" to begin fare calculation
3. Tap "Stop trip" to end and save
4. View history in "Trips" tab
5. Configure settings in "Settings" tab

### Key Features to Verify:
- Meter calculation works offline
- GPS tracking (needs location permission)
- City configuration updates fares correctly
- Night mode activates at configured times (22:00-05:00)
- Dark mode toggles properly
- Trip data persists after app close

### Note:
- This is a professional tool for auto rickshaw operators
- No in-app purchases or ads
- Data stored locally on device
- Requires location permission for GPS tracking
